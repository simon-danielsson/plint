Plint

Header-only C library for building and serving websites.

References:
- https://aosabook.org/en/500L/a-simple-web-server.html
- https://ruslanspivak.com/lsbaws-part1/
- https://joaoventura.net/blog/2017/python-webserver/
- https://github.com/KDesp73/webc

## Info

Plint is built for with single-tier architecture; the server is responsible for both processing requests and serving web content. This is adequate for small websites or applications with low traffic.
